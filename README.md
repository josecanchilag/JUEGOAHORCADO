# El Ahorcado – Capitales de Colombia

Juego web educativo del ahorcado basado en las capitales de los 32 departamentos de Colombia.
Proyecto del Segundo Parcial de Lenguajes de Programación – Universidad de Santander (UDES),
docente: Carlos Carrascal.

## Descripción

El jugador elige región y nivel, y debe adivinar la capital de un departamento colombiano
antes de agotar los 6 intentos (o los 90 segundos en nivel Difícil). Incluye pistas,
puntuación con multiplicador por nivel, estadísticas, ranking, tema claro/oscuro y
módulo de accesibilidad.

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, Grid, variables, media queries, @keyframes)
- JavaScript puro (ES6+) sin frameworks ni librerías
- localStorage para estadísticas y preferencias
- Web Audio API (sonidos) y Web Speech API (lectura en voz alta)
